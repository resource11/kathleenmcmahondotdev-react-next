# kathleenmcmahon.dev

A digital garden built with Astro and React. Live at [kathleenmcmahon.dev](https://kathleenmcmahon.dev).

Contains writing, case studies, talks, and portfolio work. Content is authored in MDX and deployed via Netlify.

Migrated from a previous Gatsby site.

## Stack

- [Astro](https://astro.build) v6
- React 19
- MDX
- Netlify

## Commands

Run from the project root using `pnpm`:

| Command | Action |
| :--- | :--- |
| `pnpm install` | Install dependencies |
| `pnpm dev` | Start local dev server |
| `pnpm build` | Build for production |
| `pnpm preview` | Preview production build locally |
